Application Météo Interactive

Description du projet:
Cette application web permet de consulter la météo actuelle ainsi que les prévisions horaires et quotidiennes pour n'importe quelle ville dans le monde.
Elle exploite l'API OpenWeather pour récupérer les données météorologiques et fournit des informations détaillées telles que:
*Température actuelle
*Humidité
*Vitesse du vent
*Ressenti thermique ("feels like")
*Lever et coucher du soleil
*Prévisions sur 5 jours
*Prévisions horaires
*Indices météo pratiques (indice de chaleur, confort du vent, conseils vestimentaires)
*Icônes météo colorées et dynamiques
L'application offre également des fonctionnalités avancées :
*Recherche avec autocomplétion pour les villes
*Sauvegarde des villes favorites dans le navigateur
*Géolocalisation pour détecter automatiquement la position de l'utilisateur
*Interface responsive avec animations fluides

Technologies utilisées:
HTML5 – structure et sémantique de la page
CSS3 – mise en forme, animations, effets visuels et gestion du thème
JavaScript (ES6+) – logique de l'application, appels API, manipulation du DOM
API OpenWeather – récupération des données météorologiques et géocodage
LocalStorage – stockage des villes favorites et préférences de thème

Fonctionnalités principales
Consultation météo complète : température, humidité, vent, lever/coucher du soleil
Prévisions horaires et 5 jours
Indices météo et conseils pratiques
Icônes météo animées et colorées
Recherche intelligente avec autocomplétion
Sauvegarde des villes favorites
Thème clair/sombre personnalisable
Détection automatique de la localisation
Interface responsive adaptée à tous les écrans

Nouveautés explorées
Durant ce projet, j'ai appris et expérimenté plusieurs concepts techniques et pratiques :
Intégration d'API tierces et gestion des données JSON en temps réel
Gestion avancée du DOM pour afficher dynamiquement les informations
Utilisation du LocalStorage pour stocker des préférences utilisateurs
Création d'une interface responsive et interactive avec animations CSS
Gestion des thèmes clairs et sombres en CSS et JavaScript
Mise en œuvre de la géolocalisation pour récupérer la position de l'utilisateur

Difficultés rencontrées
Gestion des données asynchrones avec fetch et Promise pour l'API OpenWeather.
Affichage correct des prévisions horaires et quotidiennes sans surcharge de la page.
Mise en place d'une autocomplétion efficace pour les recherches de villes.
Gestion du thème sombre et clair avec mémorisation dans le navigateur.

Solutions apportées
Utilisation de async/await pour gérer l'asynchronicité et simplifier la logique des appels API.
Structuration des données reçues pour afficher uniquement les informations nécessaires, en limitant les prévisions affichées.
Recherche et implémentation de librairies ou algorithmes simples pour l’autocomplétion et le filtrage des villes.
Stockage du choix de thème dans LocalStorage et application dynamique via CSS variables.
Tests constants sur différents écrans et utilisation de media queries pour assurer la compatibilité mobile et tablette.
Optimisation du rendu des icônes météo et couleurs pour qu’elles restent visibles et attractives quel que soit le thème.
